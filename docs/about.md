# 关于本站

- **仓库**：<https://github.com/italycalibur2019/italycalibur2019.github.io>

## 技术栈

| 组件          | 说明                          |
| ------------- | ----------------------------- |
| VitePress 1.x | 静态站点生成器                |
| GitHub Actions| 自动构建与部署                |
| GitHub Pages  | 静态托管服务                  |

## 更新站点

只需修改 `docs/` 下的 Markdown 文件，然后推送即可：

```bash
git add .
git commit -m "更新内容"
git push
```

GitHub Actions 会自动完成构建和上线。
